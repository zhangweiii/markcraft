Markdown, beautifully read in Chrome.

MarkCraft turns any .md file — on your disk or on the web — into a clean, readable document with diagrams, math and an outline. Edit it, annotate it, present it. Rendering happens locally. Optional AI and PlantUML features use the services you configure.

## Rendering

Diagrams, math and code that just render.

Mermaid flowcharts, Graphviz, WaveDrom and KaTeX appear inline — no build step, no copy-pasting into another tool. Open any diagram fullscreen, zoom and pan, or download it as SVG, PNG or JPEG.

  • GitHub Flavored Markdown, alerts, footnotes and task lists
  • 12 syntax themes, file names on code blocks, copy buttons
  • Mintlify components: Cards, Tabs, Steps, Accordions, CodeGroups

## Review & AI

Review like a document. Hand it off to AI.

Highlight in four colors, underline and comment on any passage. Turn your notes into a ready-to-paste prompt — or let the built-in agent edit a copy with the AI provider you configure, and review the diff before anything touches your file.

  • Filter by type, track what's unresolved
  • Annotations survive reloads and show up in print and exports
  • Accept or dismiss agent changes with a clear +/− diff

## Editing

Edit in place, then save straight back.

Switch between Read, a WYSIWYG editor and raw Source with one shortcut. Diagrams and formulas preview while you type, and ⌘S writes the file back to disk.

  • Live reload when the file changes — with a +/− diff you can accept
  • Folder browser with sorting, bookmarks and full-text search
  • Paste Markdown, drag & drop files, start new documents

## Present & export

From notes to slides and mind maps.

Split a document with --- and present it full screen, with your own fonts, colors and background. Or explore its structure as an interactive mind map. When it's time to share, export to Word, HTML or PDF.

  • Speaker notes, auto-play, keyboard and touch navigation
  • Mind maps download as SVG, PNG or JPEG
  • Exports keep your highlights and an optional table of contents

## Settings

Make it read the way you like.

Light, dark and sepia themes, five font families, adjustable size, line height and width. Turn individual Markdown plugins on or off, and rebind every shortcut. The interface speaks English and 简体中文.

  • Quick Settings anywhere with ⌘,
  • Import and export your settings as JSON
  • Right-to-left text detected automatically

Private by design.

No MarkCraft account, analytics or telemetry. Documents are rendered in your browser. If you configure and run the AI agent, the document, instructions and API key are sent to your chosen provider. PlantUML sends diagram source to your configured server only after you enable it and grant consent.

## Install

Up and running in a minute.

  1. 1

    Install

    Open MarkCraft on the Chrome Web Store and click Add to Chrome.

  2. 2

    Open extension settings

    Open , find MarkCraft and click Details.

  3. 3

    Allow local files

    In MarkCraft's Details, enable Allow access to file URLs. Then open any .md file.

Prefer building from source?

git clone https://github.com/zhangweiii/markcraft.git
cd markcraft && npm install && npm run build   # → dist/
